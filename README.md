# 타고 타고 옛날 여행 퀴즈

초등학교 3학년을 위한 **옛날의 교통수단** 학습 퀴즈 웹페이지입니다.

## 이렇게 진행돼요
1. 메인 화면에서 **[시작하기]**를 누릅니다.
2. 4지 선다형 문제 5개를 한 문제씩 풉니다. 이전 문제로 돌아가 답을 바꿀 수도 있어요.
3. **[최종 제출]**을 누르면 100점 만점으로 점수가 나옵니다. 한 문제는 20점이에요.
4. **[틀린 문제 확인하기]**에서 내가 고른 답, 정답, 쉬운 도움말을 볼 수 있습니다.

## 다루는 교통수단
가마 · 소달구지 · 돛단배 · 뗏목 · 인력거

## 실행 방법
설치할 것은 없습니다. `index.html` 파일을 웹 브라우저로 열면 됩니다.

## 문제 바꾸기
`index.html` 안의 `QUESTIONS` 목록에서 문제, 보기, 정답 번호(0부터 시작), 도움말을 고치면 됩니다.
